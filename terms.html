Attribution exists so promoters can be credited for gifts that come through their shared QR or link. We determine attribution using the referral code present on the donate session when checkout is created and when payment is confirmed.

We aim for accurate attribution but do not guarantee that every edge case (browser quirks, abandoned checkouts, delayed webhooks, or user error) will resolve in a promoter’s favor.
